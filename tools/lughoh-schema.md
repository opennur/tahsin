# Schema for `assets/lughoh/lessons.json` — "📚 Learn Arabic"

This document defines the JSON schema for the Learn Arabic course (a Durusul
Lughoh-inspired teaching structure). Data is generated by
`tools/build_lughoh.py` from source content in `tools/lughoh_content_*.py`.

## Originality (important)

**No copyrighted teaching material is included.** Durusul Lughoh is used only as
inspiration for the pedagogical structure (Muhadatsah → Mufrodat → Qawa'id →
Tadribat). Every dialogue, sentence, example, and exercise is written from
scratch. Nothing is copied from Durusul Lughoh, another textbook, or an online
source. `build_lughoh.py` cannot verify originality because it has no copyright
database; content authors remain responsible for never copying a source.

## Content-writing conventions

- Course content is written in **Indonesian** (the ID translation is the source
  language). UI headings, buttons, and labels remain bilingual through
  `AppStrings`.
- **English translations**: every Indonesian string MUST have an EN translation.
  Translations live in `tools/lughoh_en.py` (the key is the Indonesian text),
  and `build_lughoh.py` inserts the `*En` fields during generation. A missing
  translation fails the build; religious learning content must not silently
  fall back to the wrong language.
- Arabic is written with **full harakah** (fathah, dammah, kasrah, tanwin, and
  sukun) so it is friendly to beginners. Initial alifs use the appropriate
  seated or standing hamza.
- Latin transliteration is consistent:
  - long vowels `ā ī ū`; emphatic consonants `ṣ ḍ ṭ ẓ`; `th j ḥ kh dh sh ʿ gh`;
    non-initial hamza `'`; and no written hamza at the start of a word
    (`ana`, `anta`, `ism`).
- Dialogue speakers use Indonesian labels such as `Ahmad` and `Fatimah`.

## JSON structure

```jsonc
{
  "schemaVersion": 1,
  "generatedBy": "tools/build_lughoh.py",
  "generatedAt": "2026-01-01T00:00:00+00:00",   // ISO8601
  "levels": [
    {
      "id": 1,                                   // int, 1-based, unique
      "titleId": "Level 1 — Perkenalan & Kehidupan Sehari-hari",
      "titleEn": "Level 1 — Introductions & Daily Life",  // REQUIRED
      "titleAr": "المُسْتَوَى الأَوَّل",
      "lessons": [ ... ]
    }
  ]
}
```

### Lesson

```jsonc
{
  "id": "1-1",                                   // "<levelId>-<lessonNo>", unique
  "titleId": "Perkenalan Diri",
  "titleEn": "Self-Introduction",               // REQUIRED
  "titleAr": "التَّعْرِيفُ بِالنَّفْسِ",

  "muhadatsah": [                                // 8–10 dialogue lines
    {
      "speaker": "Ahmad",                        // label ID
      "ar": "مَا اسْمُكَ؟",                       // Arab berharakat
      "latin": "Mā ismuka?",                     // transliterasi
      "id": "Siapa namamu?",                      // Indonesian translation
      "en": "What is your name?"                 // REQUIRED
    }
  ],

  "mufrodat": [                                  // 8–10 words from the dialogue
    {
      "ar": "اِسْم",
      "latin": "ism",
      "id": "nama",
      "en": "name",                              // REQUIRED
      "exampleAr": "مَا اسْمُكَ؟",
      "exampleLatin": "Mā ismuka?",
      "exampleId": "Siapa namamu?",
      "exampleEn": "What is your name?"          // REQUIRED
    }
  ],

  "qawaid": [                                    // 2–3 kaidah tata bahasa
    {
      "titleId": "Kata tanya مَا",
      "titleEn": "The question word مَا",        // REQUIRED (Arabic terms allowed)
      "id": "Kata tanya مَا dipakai untuk bertanya tentang nama atau benda. Contoh dari dialog:",
      "en": "مَا is used to ask about a name or a thing. Example from the dialogue:",  // REQUIRED
      "exampleAr": "مَا اسْمُكَ؟",                // REQUIRED; must appear in dialogue
      "exampleLatin": "Mā ismuka?",
      "exampleId": "Siapa namamu?",
      "exampleEn": "What is your name?"          // REQUIRED
    }
  ],

  "tadribat": [                                  // ≥1 per jenis, total ~8
    { "type": "fillBlank",        ... },
    { "type": "translateArId",    ... },
    { "type": "translateIdAr",    ... },
    { "type": "rearrange",        ... }
  ]
}
```

### Tadribat (four tap-based exercise types)

**fillBlank** — choose the missing word:

```jsonc
{
  "type": "fillBlank",
  "promptId": "Isilah titik-titik: Siapa ___?",
  "promptEn": "Fill in the blank: What ___?",   // REQUIRED
  "promptAr": "مَا ____؟",
  "promptLatin": "Mā ____?",
  "options": ["اسْمُكَ", "بَيْتُكَ", "كِتَابُكَ", "قَلَمُكَ"],
  "answer": "اسْمُكَ"                            // must belong to options
}
```

**translateArId** — translate Arabic → English/Indonesian (choose a translation):

```jsonc
{
  "type": "translateArId",
  "promptAr": "مَا اسْمُكَ؟",
  "promptLatin": "Mā ismuka?",
  "options": ["Siapa namamu?", "Apa kabarmu?", "Dari mana kamu?", "Di mana rumahmu?"],
  "answer": "Siapa namamu?",
  "optionsEn": ["What is your name?", "How are you?", "Where are you from?", "Where is your house?"],  // REQUIRED
  "answerEn": "What is your name?"              // REQUIRED; must belong to optionsEn
}
```

**translateIdAr** — translate English/Indonesian → Arabic (choose an Arabic sentence):

```jsonc
{
  "type": "translateIdAr",
  "promptId": "Senang berkenalan.",
  "promptEn": "Nice to meet you.",              // REQUIRED
  "options": ["تَشَرَّفْنَا", "أَهْلًا وَسَهْلًا", "مَعَ السَّلَامَةِ", "صَبَاحَ الْخَيْرِ"],
  "answer": "تَشَرَّفْنَا"
}
```

**rearrange** — arrange words into the correct sentence (tap them in order):

```jsonc
{
  "type": "rearrange",
  "words": [                                    // URUTAN BENAR
    {"ar": "أَنَا",   "latin": "anā"},
    {"ar": "مِنْ",    "latin": "min"},
    {"ar": "إِنْدُونِيسِيَّا", "latin": "Indūnīsiyyā"},
    {"ar": "أَيْضًا", "latin": "ayḍan"}
  ],
  "answer": ["أَنَا", "مِنْ", "إِنْدُونِيسِيَّا", "أَيْضًا"]   // = ar(words) berurutan
}
```

## Validation rules (`build_lughoh.py`)

1. Structure: every required field is non-empty and uses the expected type.
2. Level IDs are unique; lesson IDs are unique and follow `<level>-<no>`.
3. `ar` may contain only Arabic letters, harakah, and Arabic punctuation
   (، ؟ .); Latin letters are not allowed. `latin` may not contain Arabic.
4. `latin` transliteration uses only ASCII plus `ā ī ū ṣ ḍ ṭ ẓ ḥ ʿ '`.
5. Every `mufrodat.ar` entry (normalized with harakah removed) appears as a
   substring of that lesson's normalized dialogue text: each word must come
   from the conversation.
6. Every `qawaid.exampleAr` entry appears in at least one normalized dialogue
   line: grammar examples must come from the conversation.
7. `fillBlank`: `promptAr` contains `____` exactly once; options are unique and
   have at least three entries; `answer` belongs to options.
8. `translateArId` / `translateIdAr`: options are unique and have at least
   three entries; `answer` belongs to options.
9. `rearrange`: `answer` equals the `ar` order in `words`; words are unique.
10. Each lesson has at least one exercise of all four types (at least four total,
    with eight as the target).
11. **English completeness is required**: every `titleId`, `id`, and `exampleId`
    field (level/lesson/muhadatsah/mufrodat/qawaid), every `promptId`
    (fillBlank, translateIdAr), and every `options`/`answer` value
    (translateArId) must have an EN pair (`titleEn`, `en`, `exampleEn`,
    `promptEn`, `optionsEn`, `answerEn`) from `tools/lughoh_en.py`. A missing
    translation fails the build. EN fields for Indonesian-only text may not
    contain Arabic letters; `answerEn` must belong to `optionsEn`. Qawaid
    titles and explanations may still contain Arabic terms such as
    `Kata tanya مَا`.

Arabic normalization removes harakah `\u064B-\u0652` and `\u0670`, then
normalizes hamza/alif variants in the same way as the app's `ArabicNormalizer`.
