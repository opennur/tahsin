# Schema for `assets/nahwu/lessons.json`

Nahwu is an original offline course for beginners. Every Indonesian text has an
English counterpart, while Arabic examples use harakah for easier reading. The
source material lives in `tools/nahwu_content.py`, and the JSON is generated by
`tools/build_nahwu.py`.

Each lesson contains `rules` and `exercises`. A `choice` exercise uses the same
answer index for its `optionsId` and `optionsEn` pairs. A `rearrange` exercise
stores its words in the correct answer order.
