# Schema for `assets/shorof/lessons.json`

The offline Shorof course contains roots, wazans, form-change examples,
conjugation tables, and exercises. Original source material lives in
`tools/shorof_content.py`; JSON is generated by `tools/build_shorof.py` and must
not be edited by hand.

Every Indonesian text has an English counterpart. Arabic text uses full harakah,
and each multiple-choice exercise has matching ID/EN option counts and the same
answer index.
